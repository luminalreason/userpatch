# Standalone redesigns

Each standalone redesign covers one group of related sites, so you can install only the sites you use. Install either HubFamily or the standalone redesigns below, not both, because they change the same pages.

HubFamily makes the Hub sites look and work like one interface that follows your system’s light or dark theme, from browsing movies and series to choosing a download server. Movie and series pages include posters, an Info section, trailers, screenshots, and quality filters. Series selections are saved. Download pages share the same server buttons, copy and share buttons, and an info dialog that explains how the mirrors differ. HubFamily also covers HUBLinks, HubCDN, and HubCloud's rotating link generator pages.
